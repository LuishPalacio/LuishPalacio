## `01 / About me`

I'm a **Computer Science student** at Centro Universitário Braz Cubas, expected to graduate in **December 2027**, and currently work as a **Mid-level IT Assistant** at ODEEN. That hands-on exposure to infrastructure, technical support and networking gives me a solid foundation in how technology operates in practice — but my career focus is **software development**.

I've directed my studies and projects toward building modern, scalable solutions, centered on **React, React Native and TypeScript**. FinFlow — my personal finance app with a built-in AI assistant — is the clearest example of that technical base. Beyond that core, I work with Python (Flask, Django), Node.js and native Kotlin, and stay actively involved with electronics and IoT (Arduino, ESP32, Raspberry Pi Pico), which reinforces my view of hardware and software integration.

My experience as an IT teacher at DiscoverON was fundamental in developing communication, teamwork and teaching skills — abilities I apply directly to solving problems as part of a team.

> I'm looking for opportunities where I can grow as a developer, with a growing interest in cybersecurity and artificial intelligence.

## `03 / Featured projects`

### FinFlow Finanças
Personal and shared finance management app, with a mobile app and a web dashboard running on the same account and the same business rules. The backend runs on Supabase (PostgreSQL, Auth and Realtime) with Row Level Security, and the AI assistant is a structured agent that turns natural language into validated database actions, always with user confirmation.
- **Technologies:** React Native, Expo Router, TypeScript, Next.js, Supabase, PostgreSQL.
- **Status:** Actively in development.

[![Repository](https://img.shields.io/badge/Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/FinFlowA/app-financas)

### FoodNode Analytics
Optimal routing system for fast-food deliveries: computes the shortest path in weighted directed graphs using **Dijkstra + BFS**, with a Tkinter desktop GUI and a CLI mode for automation. Built with a layered architecture (presentation, application, domain and infrastructure) and a suite of 65 automated tests.
- **Technologies:** Python, Tkinter, Dijkstra, BFS, Pytest.
- **Status:** Academic project (Graph Theory).

[![Repository](https://img.shields.io/badge/Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/LuishPalacio/foodnode-analytics)

### Task Management System
Web application for organizing activities, built during a Data Structures course. Focused on efficient business logic and server-side data handling.
- **Technologies:** Python, Flask.

[![Repository](https://img.shields.io/badge/Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/LuishPalacio/sistema-gerenciamento-tarefas)

### Landing Page — Ferreira & Moreira
Full ownership of development and web hosting for the company's official landing page, ensuring stability, security and the best performance for its digital presence.
- **Technologies:** HTML, CSS, JavaScript.

[![Repository](https://img.shields.io/badge/Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/LuishPalacio/ferreira-moreira-site)

### Order Management (UI Design)
Project focused strictly on prototyping and user experience (UX). Full visual interface and navigation flow design for a commercial order management system, ensuring usability and accessibility.
- **Technologies:** Figma.

[![Repository](https://img.shields.io/badge/Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/LuishPalacio/SISTEMA-DE-GERENCIAMENTO-DE-PEDIDOS)
